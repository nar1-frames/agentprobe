# Code of Conduct

AgentProbe is a small project with a security-focused mission. Contributors are
expected to be respectful, specific, and collaborative.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
deliberate exposure of private data, and using the project to test systems
without authorization.

Maintainers may remove comments, reject changes, or restrict participation when
behavior violates this standard. Report a conduct concern privately through the
contact route in [SECURITY.md](SECURITY.md).
